# Citra — product targets (PDF)

Brand: **Citra** (transitional: `pdf-reader-mcp`, `@sylphx/pdf-reader-mcp`)  
SSOT: `docs/portfolio/sylphx-instruments-ssot.md`

## Final target

Remain the category-leading **local PDF instrument for agents**:

- Citeable document twins (structure, tables, OCR, visual proof, trust)
- Fast native path, lightweight per-platform optional natives
- **SDK + CLI + MCP** all first-class
- Family template for quality, packaging, and messaging

## Tools (stable, clear)

- `read_pdf` — default auto path
- `search_pdf` — cheap literal retrieval
- `pdf_evidence` — focused inspect/render/crop/OCR/region ops

Do not merge these into one mega-tool. Improve **defaults and progressive docs**,
not tool count cosplay.

## Goals

| Goal | Notes |
| --- | --- |
| Brand | Hero/docs say **Citra**; dual-publish strategy for package name |
| SDK | Importable TS/Rust APIs with same semantics as MCP |
| Quality | Install/registry green; public benches; honest trust/OCR routes |
| Template | Other Instruments copy Citra’s surface and release rigor |

## Non-goals

- Absorbing Iris/Cue/Lookout
- Hosted multi-tenant OCR platform as product core
