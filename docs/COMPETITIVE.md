# Spine — competitive positioning

## Job

Repository architecture evidence engine

## Wedge

Local deterministic architecture index with search/path/trace/impact and file:line evidence — no required LLM pipeline.

## Local-first

Indexes local repo roots; no cloud graph service required.

## Peer anchors (learn; do not clone)

| Peer | Gap we exploit |
| --- | --- |
| Egonex-AI/Understand-Anything | LLM multi-agent knowledge graph + tours; powerful but API/cost heavy and generative |
| Code search / RAG MCP tools | Retrieval chunks without architecture path/trace/impact evidence graph |
| Language servers alone | Symbol truth, not repo architecture packs for agents |

## Non-goals

- Becoming a cloud SaaS wrapper as the default path
- Multi-product monorepo for star aggregation
- Generative summaries as the sole evidence authority
