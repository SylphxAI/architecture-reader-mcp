# ADR-3: Product brand name Spine

Date: 2026-07-31  
Status: Accepted  
Slug: product-brand-spine

## Context

This repository ships an architecture MCP/engine. Category SKU naming
(`architecture-reader-mcp`) is weak for product identity.

## Decision

Public product brand for **this repository** is **Spine**.

- Transitional package: `@sylphx/architecture-reader-mcp`
- Brand CLI: `spine` (bin in this repo)
- Other Sylphx products keep their own brands in their own repositories.

Company-level Instruments composition is not defined or owned by this ADR.

## Consequences

README and package marketing use Spine for this product only.
